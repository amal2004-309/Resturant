# 🍔 Foodie - Restaurant & Food Delivery Website

A responsive and interactive **Restaurant & Food Delivery** web application created using **HTML5** and **CSS3**. The project features a modern UI with animated sections, product showcases, customer reviews, dynamic ordering forms, and smooth responsive navigation for all screen sizes.

---

## 🚀 Features

* **Responsive Navigation Header:** Sticky header with active links and mobile-friendly toggle navigation bar.
* **Hero Section:** Engaging landing section with custom CSS animations (`float` effect).
* **Speciality & Popular Menus:** Flexbox/Grid-based layouts displaying food items, descriptions, dynamic tags, and pricing tags.
* **Interactive Ordering System:** Clean multi-input form section for placing orders.
* **Customer Reviews & Steps:** Styled testimonials and standard step-by-step order procedure visuals.
* **Cross-Device Compatibility:** Optimized for Desktop, Tablet, and Mobile devices using CSS Media Queries.

---

## 🛠️ Tech Stack & Concepts Used

* **HTML5:** Semantic HTML structure (`<header>`, `<section>`, `<nav>`, `<form>`).
* **CSS3:** Custom Properties (CSS Variables), Flexbox Layout, Keyframe Animations, CSS Transitions.
* **FontAwesome:** Scalable vector icons for clean visual indicators.
* **Responsive Web Design:** Fluid layouts using relative units (`rem`, `%`) and `@media` queries.
